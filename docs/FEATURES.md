# MaxLauncher — выбор фич

Лаунчер в стиле Samsung One UI Home (One UI 8.5) для любых Android-телефонов (Xiaomi, Poco и т.п.),
без зависимостей от библиотек Samsung.

Документ фиксирует, какие фичи One UI Home решено переносить, а какие нет. Отклонённые фичи
оставлены в списке, чтобы их можно было пересмотреть и включить позже.

**Статусы**
- ✅ **Делаем** — входит в первую версию (MVP)
- ⏸ **Не делаем** — отложено по решению, можно пересмотреть
- ⛔ **Невозможно** — недоступно стороннему лаунчеру без root / системных прав

★ — ключевые требования из исходной постановки.

Дата решения: 2026-10-12.

## Принятые решения по поведению

### Жесты (п.15, п.44)
- **Главный экран:** вертикальный свайп **вверх или вниз** открывает меню приложений.
- **Меню приложений:** вертикальный свайп **вверх или вниз** закрывает меню.
  Горизонтальный свайп листает страницы.
- **Шторка уведомлений:** лаунчер её не обрабатывает. Свайп вниз от края экрана
  (строка состояния) открывает шторку силами системы.
- **Кнопка «Домой» на главном экране:** закрывает открытое меню приложений или папку.
  На домашний экран не перелистывает (п.46).

### Папки
- **Папки главного экрана и папки меню приложений независимы.** Это разные сущности,
  как у Samsung. Одно и то же приложение может лежать в папке на главном экране и
  в папке меню.
- **Приложение, лежащее в папке меню, не показывается в общем списке меню.**
- **Папки в меню сортируются между собой** по тем же правилам, что и приложения.

### Правила сортировки (п.17, п.18)
Порядок в меню приложений:
1. Сначала папки, затем приложения.
2. Внутри каждой группы:
   1. Названия на цифры и символы — по стандартным правилам сортировки (`Collator`):
      цифры и символы идут перед буквами.
   2. Русские названия (кириллица) — по `Collator` для `ru`.
   3. Английские названия (латиница) — по `Collator` для `en`.
   4. Прочие алфавиты — в конце.
3. Сравнение без учёта регистра; «ё» сортируется вместе с «е» (стандарт `Collator`).

Положение цифр и символов можно пересмотреть позже, например перенести их в конец.

## Известные ограничения на Xiaomi / Poco (MIUI / HyperOS)
- Экран «Недавние» и анимации возврата в иконку остаются системными (п.47).
- На части версий MIUI/HyperOS жесты навигации с ограничениями работают со сторонним лаунчером.
  Это нужно проверить на реальных устройствах.
- Accessibility Service (п.45) MIUI может выключать после перезагрузки.
  Пользователю нужно разрешить автозапуск и отключить ограничения батареи для лаунчера.

## Состояние реализации (2026-10-12)

Все фичи со статусом ✅ реализованы. Проверено на эмуляторе (Android 16) и на Galaxy S23+
(One UI 8.5, Android 16).

Поведение, выбранное при реализации:
- **Перетаскивание из меню приложений** остаётся внутри меню: приложение на приложение — папка,
  на папку — добавить в папку, на пустое место — убрать из папки. Чтобы положить приложение
  на главный экран, его тянут на кнопку «На главный экран» внизу (появляется вместо поиска).
- **Папки на главном экране** — приложения внутри тоже по алфавиту, ручного порядка нет.
- **Занятая ячейка**: значок встаёт в ближайшую свободную (иконки не раздвигаются, как у Samsung).
- **Ярлыки от других приложений** (закладка, контакт) добавляются без дополнительного вопроса.
- **Виджеты** добавляются на текущую страницу в первое свободное место; при первом виджете
  Android спрашивает разрешение «Создать виджет».
- **Двойной тап** работает только после включения службы «MaxLauncher: выключение экрана»
  в «Специальных возможностях» (по-другому Android сторонним лаунчерам выключать экран не даёт).

Известные ограничения:
- **Пауза рабочего профиля** — кнопка «Включить» есть, но не проверена.
